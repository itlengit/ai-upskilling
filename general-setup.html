Setup guide

Get access to course tools

Before starting the exercises, get a DIAL key to call models through the API and access to two AI coding assistants: CodeMie and GitHub Copilot.

1

DIAL API key

You need this key to call models from your exercise code.

  1. Open EPAM DIAL Service in the Support Portal and select Request DIAL API Key.
  2. Once your request is approved, copy the key you receive.
  3. Install Node.js 20.6 or later. Create an .env file in the module folder and add these settings, replacing the placeholder with your key: 
    DIAL_API_KEY=your_key
DIAL_ENDPOINT=https://ai-proxy.lab.epam.com
DIAL_MODEL=gpt-4.1-mini-2025-04-14
DIAL_API_VERSION=2024-02-15-preview
  4. Add .env to .gitignore.
  5. Run your code with the environment file: 
    node --env-file=.env index.js
    Access the settings through process.env, for example process.env.DIAL_API_KEY.
Never publish your key or commit it to Git.
2

CodeMie CLI

CodeMie CLI is a command-line tool for working with CodeMie AI assistants.

  1. Install Node.js 20 or later.
  2. Install the CLI: 
    npm install -g @codemieai/code
  3. Run the setup wizard and sign in with EPAM SSO: 
    codemie setup
  4. Check your setup: 
    codemie doctor
  5. Choose a coding assistant, install it, and launch it from your project folder (you only need one):

    Claude Code

    codemie install claude --supported
codemie-claude

    OpenAI Codex

    codemie install codex --supported
codemie-codex

    Gemini CLI

    codemie install gemini
codemie-gemini
    For more assistants and launch options, see the CodeMie README.
3

GitHub Copilot

  1. Open EPAM Telescope — AI and search for GitHub Copilot.
  2. Request access and wait for approval.
  3. Sign in to GitHub with your work account linked to EPAM and install the GitHub Copilot extension in VS Code.
